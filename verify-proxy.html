TLSNotary Proxy Attestation Auditor

Checks that an enclave-signed record of a notarized HTTPS session is intact — offline, in your browser, with no third-party code.

Nothing is uploaded. Paste the response body exactly as you received it: the signature covers the bytes of the first ten fields, so this page reads your text rather than re-serializing it. Re-formatted (pretty-printed) input is accepted too, and the page says so when it has to strip whitespace to rebuild the signed bytes.

The notary's key is generated per boot, so the record can only say "signed by this key". Paste this boot's attestation report — the same JSON the login hands back, or a raw /debug/envelope response — and this page checks the record's key against the key the report names. That report is what verify.html audits against the TDX quote and the pinned measurements; this page cannot repeat that check, and does not pretend to.
